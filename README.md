# Tower of Hanoi

1. On GitHub, select **Use this template**.
2. Select **Open in a codespace**.
3. Open `Hanoi.java`.
4. Complete the body of `hanoi`.

Save the file. Run these commands in the terminal.

```sh
javac Hanoi.java
java Hanoi
```

The program should print one legal move per line, in order. Use your kit to check the printed moves.

If you use VS Code on your computer, clone this repository. Run the same commands from the folder that contains `Hanoi.java`.
